5자연어 → Agent 자동 라우팅 + 동적 Escalation

박정운이 자연어로 요청해도 메인 LLM이 agent description TRIGGER 매칭 → 자동 위임. 한계 감지 시 ai-engineer로 Escalation.

"이 안드로이드 코드 봐줘"
1
메인 LLM이 요청 1초 점검 → CLAUDE.md "Agent 우선 활용 매트릭스" 확인
2
TRIGGER 매칭: "안드로이드 코드", "코드 봐줘" → android-developer-agent + code-quality-agent
3
단일 메시지에 multiple Agent tool 호출 → 병렬 spawning (Sonnet × 2)
4
각 agent 결과 → 메인 LLM이 통합 → 박정운에게 보고
⚡ 한계 감지 시 Escalation: 다층 trade-off 분석 필요 → "ai-engineer(Opus)에 위임합니다" 한 줄 보고 후 Opus 호출

ai-engineer · android-developer · code-quality · tester · error-detective · doc-manager · planner · 14 GSD 등

한국어/영어 TRIGGER 키워드 추가 → 자동 위임률 ↑

8박정운 이해 검증 체크리스트

아래 항목을 보고 "맞다/이해 됨"이면 ✓, "헷갈림"이면 표시 후 알려주세요.

  • Jungki vault는 iCloud + Git 양쪽 동기화, 5층 분리(wiki/raw/work-private/personal-private/setup)
  • 회사 맥은 본업 + 수동 / 개인 맥은 자동화 본거지 (cron·launchd 한 대만)
  • 공통 룰 파일(CLAUDE.md·index·log·setup) 수정은 pull→편집→push 강제
  • Karpathy 3-동작(Ingest·Query·Lint) — 오늘 Lint 첫 실행으로 모두 가동
  • 슬래시 25개는 frontmatter model:로 자동 모델 분기 (Haiku 4·Sonnet 19·Opus 2)
  • 자연어로 요청해도 메인 LLM이 agent TRIGGER 매칭으로 자동 위임 시도 (PROACTIVELY)
  • 한계 감지 시 ai-engineer(Opus)로 Escalation = 반-자동 안전망
  • setup/global-CLAUDE.md가 글로벌 룰 단일 소스, ~/.claude/CLAUDE.md는 sync 사본
  • sync-global.sh --auto는 mtime 비교해서 더 최신 쪽으로 자동 양방향 sync
  • 새 프로젝트는 overview만 생성 (Lazy Seed) — 5종 stub 미리 만들지 않음
  • 비용 추적 wiki(jungki-llm-costs.md)에 routine별 토큰·비용 누적 예정
  • 다음 한 수: 개인 맥에서 launchd 등록 (worklog 22:30 / daily-end 23:55)
