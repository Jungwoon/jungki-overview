3
Knowledge-index 자동 갱신
새 wiki 페이지·새 agent → agent-knowledge-index.md에 한 줄 추가. /lint 월 1회 stale 점검
4
메타 학습 회고
/weekly · /monthly에서 agent 호출 분포·미사용 agent·실패 패턴 분석 → agent 풀 진화
5
실패 학습 Postmortem
박정운 정정·재요청·작업 실패 시 → feedback 메모리 + gotchas.md G번호 추가 + 영향받는 agent 보강
자가 진화 안전 가드 7개
  1. 변경 흔적 강제 (HTML 주석 timestamp + 이유)
  2. diff commit 분리 (chore(agent-evolve): ...)
  3. 주간 검토 강제 (/weekly에서 박정운 유지/되돌리기 결정)
  4. 자동 진화 금지 영역: frontmatter (name·description·model·tools) · 기존 본문 삭제 · 박정운 안전 규칙
  5. 악의적 진화 감지 시그널 (rate limit·박정운 의도 반대 방향·자기 정당화)
  6. 롤백 절차 (git revert + feedback 메모리)
  7. 사람-in-the-loop 강제 영역: TRIGGER 키워드 추가/삭제·tools 목록·50줄+ 큰 본문
